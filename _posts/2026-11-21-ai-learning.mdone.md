현재 프로그래밍과 인공지능 분야의 기초 지식을 학습하고 있습니다.

## 학습 내용

- 프로그래밍의 기본 개념과 활용 방법
- 인공지능의 기초 원리-

## GitHub Pages 실습

GitHub Pages와 Jekyll을 활용하여 개인 포트폴리오 웹사이트를 제작했습니다.

웹사이트를 직접 수정하고 배포하면서 Markdown 문서 작성과 GitHub의 기본적인 사용 방법을 익혔습니다.

## 앞으로의 목표

프로그래밍과 인공지능에 대한 이해를 높이고 배운 내용을 실제 프로젝트에 적용해 보고 싶습니다.

앞으로도 학습 과정과 프로젝트 경험을 꾸준히 기록할 계획입니다.
